# 2026-10-18 组件桌面后续迭代

本轮只修改 Windows 客户端。较早阶段用户正在使用电脑，界面验收由用户协助，更新前保留当时运行的进程。随后用户外出并明确允许接管电脑，已完成本轮原生窗口操作及十组件保存、恢复验收；本轮未修改或烧录 ESP 固件，也未写入 ESP 配置。

## 交付内容

- 组件编辑：60 步撤销/重做、独立草稿恢复、无效落点提示、组件库预览、添加前尺寸选择与空位建议。
- 数据组件：按尺寸显示数值、单位、内存容量、峰值和趋势；小卡缺失数据明确标记。CPU/GPU 型号、来源 ID 与长诊断段落从主页移至悬浮提示和传感器窗口。小仪表盘的长读数限制在可用区域，悬浮提示保留完整数值。
- 风扇控制：手动、自动、全速使用对应面板。自动模式的曲线与温度来源明确标为本机预览，固件尚未对齐的功能不会显示为已执行。
- 数据有效性：PC 采样和 ESP 转速通知分别判断过期；真实零值保留，缺失值不补零，演示数据有显式标记。
- 传感器窗口：可选每两秒刷新，标记主页采用的来源，刷新保留选中项与位置，关闭后停止刷新。

额外修正了编辑与数据更新相互影响的问题：等价设置通知不会清除正在编辑的布局；异步保存失败保留完整草稿与撤销历史；某项传感器短暂断读会留下曲线断点，恢复同一来源不会清空历史。趋势绘制与峰值使用同一段有界历史。

内置风扇卡按实际可用空间调整行高和字号，空间不足时收起来源页脚，保留三颗或五颗风扇的全部读数。风扇控制卡在最小尺寸下使用紧凑排布，原有合法布局继续适用。
