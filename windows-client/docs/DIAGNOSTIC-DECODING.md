# 接口自检：逐行展开解析

接口自检表左侧的小箭头可以独立展开或收起每个接口；支持同时展开多行。展开只显示已有数据，不执行写入，也不改变下方选中的写入目标。

先点击“运行读取自检”，再展开查看：

- 中文摘要、字段名、解析值与单位、类型和字节偏移。
- 原始 HEX、特征 UUID、数据来源及取得时间。
- 八种灯效各自的颜色、切换/渐变时长、颜色数组、环绕范围与速度等参数。
- 风扇和灯效枚举、亮度百分比、刷新周期与换算频率，以及电脑遥测与五槽位风扇数组。

`fan_rpm` 不支持 READ，显示最近收到的 ESP32 转速通知。该接口的写入值是目标 RPM，不会覆盖通知字段。当前固件通知仍可能使用测试值，通知来源不等于真实硬件测速已验收。

电脑遥测行解析的是 ESP32 缓存中的值，不是重新读取电脑传感器。初始 0 不证明电脑当前读数为 0。RAM/VRAM 协议单位尚未确认，保留原始 double 并标注待确认；不擅自标成 GiB。`fan_pwm` 会明确说明固件恒回 0 的限制。

空载荷、错误长度、非法枚举、NaN/Infinity 和非法数组等返回解析错误。读取失败清除旧载荷并显示原因；断连后清除上次会话载荷。单行的展开状态独立保留，重新读取会更新当前展开内容。

## 实现

`SmartFan.Core/Protocol/DiagnosticPayloadDecoder.cs` 复用 `PacketCodec` 的验证和解码，输出展示字段。`DiagnosticRow` 持有来源、原始 HEX、解析结果与展开状态；`Views/DiagnosticsView.xaml` 承载自检页，`DisclosureToggle` 提供可键盘操作的小箭头与短时旋转，遵守系统减少动画设置。

整个表格只使用一层物理像素滚动，详情按内容自然排版，没有内部 ScrollViewer、固定最大高度或拦截滚轮的处理器。27 项固定接口不启用行/列回收；滚动时保留各行实例和独立展开状态。鼠标位于行边缘或详情中央时滚动同一个列表，长数组的末尾字段也可连续滚到。展开项被视口裁切时，点击箭头会将该项移入视野。

### 展开后滚动问题修复

先前版本在行边缘使用整行滚动，会一次跨过整块详情；详情中的独立 ScrollViewer 又会消耗滚轮，未溢出时表现为中央无法滚动。之前限制内部高度、拦截详情滚轮的尝试也未解决用户实际操作问题。

本轮移除嵌套滚动、内部高度限制和滚轮拦截，改用上述单层连续滚动。旧整行滚动的负对照在未读取的 `light_mode` 上复现“一格滚轮跳过整块详情”。
