# Wind-Pressure-Laptop-Cooler

SmartFan is an ESP32-S3 based laptop cooler controller with a Windows client and
custom PCB revisions.

## Repository layout

- [`ESP-IDF/`](ESP-IDF/) — ESP32-S3 firmware (ESP-IDF, BLE, fan/PWM/tach, OLED, ARGB)
- [`APP/`](APP/) — Windows C# client (SmartFan)
- [`PCB/`](PCB/) — EasyEDA Pro PCB revisions (`v0`, `v1`, `v2`)
